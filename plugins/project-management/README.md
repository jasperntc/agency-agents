# Project Management

7 specialists from [The Agency](https://github.com/jasperntc/agency-agents).

## Enable

Add to your project's `.claude/settings.json`:

```json
{
  "extraKnownMarketplaces": {
    "agency": {
      "source": { "source": "github", "repo": "jasperntc/agency-agents" }
    }
  },
  "enabledPlugins": { "project-management@agency": true }
}
```
